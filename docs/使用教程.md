# 使用教程：从装好到打出第一叠发票

面向第一次用的人。按本文走一遍约 10 分钟，之后每次报销只需要「拖进去 → 打印」两步。

以 **Windows** 为主写（报销打印的主战场）；macOS 的差异在每节末尾单列。
想了解原理与边界的，看 [打印与导出参考](打印与导出参考.md) 与 [桌面端参考](桌面端参考.md)。

---

## 0. 先说清它能干什么、不能干什么

**能：**

- 把一堆发票 PDF / 图片 / OFD / XML 拖进来，自动识别号码、日期、购销方、金额
- 按 A4 排好版：一张纸放 1 / 2 / 4 张，自动选横竖，画裁切线
- 自动跳过重复票，提示「这张你报过了」
- 算合计（红冲票会抵扣）、凑票、导出 Excel
- **全部在本机跑**：断网可用、不上传、没有账号

**不能（这些是边界，不是待办）：**

- **不能把 OFD / XML 还原成发票原样**。数电票的 OFD / XML 里只有结构化数据、没有票面图像，
  打出来的是一张**信息卡**（号码 / 金额 / 日期 / 购销方）。见 [第 6 节](#6-ofd-与-xml-票会打成信息卡)。
- 不做报销单填写、不做发票查验、不对接任何税务系统。
- 不认识火车票 / 行程单的版面（能导入、能打印，但识别不出字段）。

## 1. 安装

1. 到 [Releases](https://github.com/rexlin0624/invoice-print/releases/latest) 下载
   `invoice-tool_<版本>_windows_x64-setup.exe`。
2. 顺手核一下下载是否完整：同页面的 `SHA256SUMS.txt` 里记了每个包的哈希。

   ```powershell
   Get-FileHash -Algorithm SHA256 .\invoice-tool_0.5.1_windows_x64-setup.exe
   ```

   把输出的一串字符和 `SHA256SUMS.txt` 里对应那行对一下，一致就没问题。
3. 运行安装包。**安装包未做代码签名**，Windows 会弹一次「已保护你的电脑」：
   点**「更多信息」→「仍要运行」**。只拦这一次。
4. 从开始菜单打开「发票工具」。

> 第一次打开后建议做一件事：点右上角**帮助**，确认「本机 OCR 中文模型」是就绪状态。
> 发布包自带模型（约 24 MB），扫一张图片发票试试，见 [第 9 节](#9-出问题先看这里)。

**macOS**：按芯片选 dmg（Apple 芯片 `aarch64`，Intel `x64`），拖进「应用程序」；
首次打开要**右键 → 打开**（未公证，双击会被 Gatekeeper 拦），之后就能正常双击。

## 2. 走一遍完整流程

### 2.1 导入

打开「合并打印」，把发票**拖进窗口**，或点「点击选择文件」。

- 支持 PDF、OFD、XML、图片，以及装了这些的 **ZIP 压缩包**
- 也可以直接 **Ctrl + V 粘贴截图**
- 一次拖几十张没问题；单文件上限 200 MB
- **你的原始文件不会被修改或删除**，工具只读它

### 2.2 看一眼识别结果

列表里每行是识别出来的号码、金额、销售方、票种。重点看两个数：

- **顶部汇总条**的「已识别号码 N/N」—— 不是 100% 就说明有票没认出号码
- **有没有带 ⓘ 的行**—— 有问题或需要确认的票会标出来

点某一行的 **ⓘ** 能看到每个字段的来源（XML / 二维码 / PDF 文字层 / OCR）与可靠程度，
并可以**对着原图改字段、补录号码**。改过的字段会标成「手工填写」，立刻参与合计与查重。

> 号码没认出来不要硬打印：报销单要填号码，缺了还得回头补。
> 汇总条上直接有「N 张要补录」的入口。

### 2.3 选每页几张

工具栏上是 **1 张 / 2 张 / 4 张**。

- 发票是 A4 一半大小（那种长条状的数电票 PDF）：**2 张**最稳
- 小票、定额发票：**4 张**省纸
- 拿不准就先点「下载 PDF」，看一眼再决定

### 2.4 打印

点**「打印」**。桌面版会把合成好的 A4 PDF 交给系统：

- 没在设置里选打印机 → **弹打印对话框**（和系统里打印别的 PDF 一样）
- 选了具体打印机 → **直接发过去**，不弹窗（Windows 上需要 SumatraPDF，见 [第 5 节](#5-选打印机跟随系统还是指定一台)）

⚠️ **打印对话框里一定要选「实际大小」/ 缩放 100%**，不要勾「适应页面」「适合边框」。
勾了会把版面整体缩小，裁切线对不上票、偏移量也没法校准 —— 这是报销打印最常见的返工原因。

点**「下载 PDF」**则得到一个合成好的 A4 文件（矢量内嵌原票面，不降清晰度），
可以自己用任何 PDF 阅读器打印，或发给同事。

### 2.5 标记已报销

打印成功后会问一句「标记为已报销吗」。建议**勾上**：

- 下次导入同一张票时会提醒「你报过了」
- 票据字段与原文件存进本机库，日后能搜到、能「再打一份」

## 3. 常用设置（「⚙ 更多设置」里）

| 设置                 | 什么时候开                                             |
| -------------------- | ------------------------------------------------------ |
| 每页张数 / 方向      | 默认「自动」就够；票据尺寸整齐时可手动指定更省纸        |
| **裁掉白边**         | 票面四周留白很大、想多省一点纸。**多页票不裁**（各页边界不同） |
| 裁切线               | 要手工裁开时开（默认开）                                |
| 页脚页码             | 页数多、怕散落时开                                      |
| **黑白打印**         | 彩色墨贵 / 老激光打印机；会先转成像素，清晰度略降        |
| **老打印机兼容**     | 打印出来是空白、乱码、缺字时开（整份转成图片再打）      |
| **打印校准（偏移）** | 打出来整体偏了才调，见 [第 4 节](#4-打出来偏了校准三步) |
| 排版预设             | 一套设置调好了存起来，换纸型、换打印机一键切回          |
| 公司抬头 / 税号      | 填了会提示「抬头不一致」的票                            |

## 4. 打出来偏了：校准三步

打印机进纸都有几毫米误差，版面整体偏一点是正常的。

1. 在「更多设置 → 打印校准」里点**「打印校准测试页」**（一页方格 + 直尺）。
2. 量蓝框到纸边的四边距离，按**100% / 实际大小**打。
   - 直尺量出来**不是 100 mm** → 说明打印机在缩放，那是打印驱动设置的问题，
     先把对话框里的缩放改回 100%，**别用偏移去凑**。
3. 把偏差填进「偏移 X / Y（mm）」：偏右 → X 填负数；偏下 → Y 填负数。范围 ±20 mm。

一次调好就一直有效，换打印机再量一次。

## 5. 选打印机：跟随系统，还是指定一台

「更多设置 → 打印机」：

- **跟随系统（弹打印对话框）** —— 默认。最不容易出错，可以在对话框里选份数、双面、纸盒。
- **指定一台** —— 选定后直接发过去、不弹窗，适合「每次都打同一台、不想多点一次」。

Windows 上**指定打印机需要 SumatraPDF**（免费、免安装，[官网下载 portable 版](https://www.sumatrapdfreader.org/download-free-pdf-viewer)）。
原因很实在：Windows 没有可靠的「静默把 PDF 打到指定打印机」的系统接口，而 SumatraPDF 有
（`-print-to`）。它免安装，解压到下面任意一个位置、重开本应用就能被找到：

- `%LOCALAPPDATA%\Programs\SumatraPDF\`（推荐）
- `%LOCALAPPDATA%\SumatraPDF\`
- `C:\Program Files\SumatraPDF\`

> 我们**不随包分发** SumatraPDF（它是 GPL-3.0，随包分发要一起提供源码）。
> 这里只是「调用你已经装好的软件」。没装的话，指定打印机的选项会灰掉并说明原因。

⚠️ 指定了某台打印机、又找不到 SumatraPDF 时，本工具会**报错并停下来**，
不会偷偷改发给默认打印机 —— 打错机器比打不出来麻烦得多。

**macOS**：不用装任何东西，`lp -d` 直接支持，选了就能用。

## 6. OFD 与 XML 票：会打成信息卡

这是**最需要提前知道**的一件事：

- 数电票下载的 **OFD / XML 里只有结构化数据，没有票面图像**
- 本工具会从中提取号码、金额、日期、购销方，然后打出一张**信息卡**
- 信息卡**不是发票原样**，顶部有醒目的「信息卡 · 非票面原样」条，卡片上还有文件名

导入时如果有这类票，界面上会有一条黄色横幅说明有几张、为什么；
点「打印」时还会再确认一次，你可以选择**「剔除这些票」**把它们从本次打印里去掉。

**想要真正的票面，有两个办法：**

1. 开票方 / 报销系统一般会同时提供 **PDF 版**——优先用 PDF，那是矢量原样
2. 用支持 OFD 的阅读器（如数科 OFD 阅读器）**把 OFD 另存 / 打印成 PDF**，再导入本工具

信息卡本身能当凭证摘要用（报销单上贴一张、附号码金额），但**替代不了发票原件**。

## 7. 另外四个页面

| 页面         | 什么时候用                                                             |
| ------------ | ---------------------------------------------------------------------- |
| **查重**     | 一批票拿不准有没有重复的，先看这里；自动跳过的可以在这里「撤销，全部打印」 |
| **转 Excel** | 要给财务明细表、要贴进报销系统模板                                     |
| **凑票**     | 「这次要凑够 3000 」——自动挑一组，红冲票不参与                        |
| **已报销库** | 搜以前的票、再打一份、看备份                                           |

红冲（负数）票会被单独认出来：照常打印，但金额从合计里**抵扣**（给的是净额），
凑票时排除，查重时和原票配成一对提示。

---

## 8. 数据在哪、怎么备份

- 一切都在本机：桌面版的数据目录（**帮助 → 桌面版 → 在文件管理器里显示**）里有
  已报销库备份与运行日志；网页版存在浏览器 IndexedDB（清浏览数据会没）
- 每次库变动都会自动留一份**库清单备份**，换机器时复制它即可（原文件字节不在备份里）
- 卸载不会自动删数据目录；想彻底清掉，手动删那个文件夹

## 9. 出问题先看这里

| 现象                             | 先看这个                                                                                     |
| -------------------------------- | -------------------------------------------------------------------------------------------- |
| 点了打印没反应                   | ① 对话框可能被别的窗口挡住了，看任务栏；② Windows「跟随系统」需要一个能读 PDF 的程序（Edge 就行），装个 SumatraPDF 最省事；③ 实在不行用「下载 PDF」自己打 |
| 打出来是空白 / 只有一半 / 缺字   | 开「老打印机兼容」再打一次（整份转成图片）                                                   |
| 打出来整体偏了                   | [第 4 节](#4-打出来偏了校准三步) 校准                                                         |
| 打出来变小了、裁切线对不上       | 打印对话框里勾了「适应页面」，改成 **100% / 实际大小**                                        |
| 金额、销售方识别不出来           | 点该行 ⓘ 看来源：只有 OCR 结果（置信度低）就对着原图校正；扫描件建议先确认 OCR 模型就绪      |
| 提示「没有离线 OCR 中文模型」    | 发布包自带；源码运行时执行一次 `pnpm ocr:prepare` 再刷新                                      |
| 一张票被自动跳过了               | 查重页里「撤销，全部打印」；文件相同或代码 + 号码且字段一致才会自动跳过                       |
| 合计金额和手算对不上             | 有红冲票时合计是**净额**（已抵扣）；「N 张没金额」的票不按 0 元算，单独计数                   |
| 安装时被 Windows 拦下            | 「更多信息」→「仍要运行」。安装包未签名，这是个已知情况                                       |
| 杀毒软件报警                     | 未签名的自发布程序**可能**被误报。可以拿 SHA256 对一下发布页，或直接用网页版（免安装）        |

## 附：网页版（免安装）

下载 `invoice-tool_<版本>_web.zip`，解压后当静态站点托管即可，也可以本机跑：

```bash
cd invoice-tool-web
python3 -m http.server 8080
# 打开 http://localhost:8080
```

网页版功能一样，只是打印走浏览器（⌘/Ctrl + P），已报销库存在浏览器里（清数据会丢）。
